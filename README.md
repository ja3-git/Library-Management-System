# Library Management System

A Python-based Library Management System using SQLite for persistent data storage.

## Features
- Add and view books
- Register and view members
- Issue and return books
- Track available book quantities
- View transaction history
- Store data in an SQLite database

## Technologies
- Python
- SQLite
- VS Code
- GitHub Projects

## How to Run
1. Install Python.
2. Download the repository.
3. Open the project folder in VS Code.
4. Run `python main.py`.

The database and tables are created automatically when the program starts.

## Project Files
- `main.py` — Main menu
- `database.py` — Database connection and table creation
- `books.py` — Book management
- `members.py` — Member management
- `transactions.py` — Issue and return operations
- `view_data.py` — View database records

## Database
The application uses SQLite. The local `library.db` file is generated automatically.
